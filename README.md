# Minimax

Implémentation d'un agent basé sur la connaissance (KBA) capable de résoudre le jeu du Démineur par inférence logique. La logique de l'IA repose sur la représentation de connaissances et la manipulation de phrases logiques pour déduire la position des mines avec certitude.


# SetUp

```bash
git clone https://github.com/cestbryan-ng/KBA-Minesweeper.git
cd KBA-Minesweeper
pip install -r requirements.txt
```
